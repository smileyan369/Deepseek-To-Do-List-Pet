# 运行与打包

在 Windows 的 Python 3.12 环境执行：

```powershell
python -m pip install -r requirements.txt
python tools/prepare_deepseek_assets.py
python main.py
python -m PyInstaller --noconfirm --clean desktop_pet.spec
```

`prepare_deepseek_assets.py` 读取 `人物设计图片` 中已确认的动作原图，生成应用实际使用的透明 `assets/deepseek/*.png`。只有原图变化时才需要重新执行；脚本不会覆盖原图。

生成绿色单文件为 `dist/待办桌宠.exe`。为兼容已有版本，数据仍保存在 `%APPDATA%\\深海待办桌宠`，因此重命名升级后任务、位置、聊天记忆和 API 配置不会丢失；可执行文件可移动。开机自启使用当前用户 `HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run`。

运行后可在任意程序中按 `Ctrl+Shift+Z` 全局切换桌宠显示/隐藏。若该组合键已被其他软件占用，应用会通过托盘消息提示，其他功能不受影响。

聊天 API 配置保存在 `%APPDATA%\\深海待办桌宠\\chat_config.json`，不写入源码目录；聊天 API Key 和可选的 Tavily 搜索 Key 均使用 Windows DPAPI 机器范围加密，复制到其他电脑后不能解密。仓库根目录的 `.gitignore` 还会排除 `.env`、聊天配置、聊天记录、本地任务数据、构建目录和临时目录。上传 GitHub 前不要把 `%APPDATA%` 中的用户数据手动复制进仓库。

联网搜索采用三级策略：配置 Tavily Search API Key 后优先调用 `https://api.tavily.com/search`；没有 Key 或 Tavily 失败时使用无需 Key 的 Bing HTML 公共搜索；Bing 失败后再尝试 DuckDuckGo 公共搜索。Tavily 提供免费额度，具体额度以其官方页面为准。若三个搜索源都不可用，程序会继续请求聊天模型进行离线回答，并明确约束模型不能编造最新结果、实时数据或来源网址。询问“现在时间/几点”时直接读取本机时间，不调用网络。

角色创意工坊文件放在 `%APPDATA%\\深海待办桌宠\\characters`，也可放在 `.exe` 同级的 `characters` 文件夹。首次通过托盘“创意工坊 -> 打开角色目录”时，程序会生成格式说明和 `character.example.json` 模板。
