# 运行与打包

在 Windows 的 Python 3.12 环境执行：

```powershell
python -m pip install -r requirements.txt
python tools/prepare_deepseek_assets.py
python main.py
python -m PyInstaller --noconfirm --clean desktop_pet.spec
```

`prepare_deepseek_assets.py` 读取 `人物设计图片` 中已确认的动作原图，生成应用实际使用的透明 `assets/deepseek/*.png`。只有原图变化时才需要重新执行；脚本不会覆盖原图。

生成绿色单文件为 `dist/待办桌宠.exe`。为兼容已有版本，数据仍保存在 `%APPDATA%\\深海待办桌宠`，因此重命名升级后任务、位置、聊天记忆和 API 配置不会丢失；可执行文件可移动。开机自启使用当前用户 `HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run`，注册命令包含 `--autostart` 标记；通过该入口启动时会主动清除隐藏状态并显示桌宠，普通手动启动仍按已有设置恢复。

运行后可在任意程序中按 `Ctrl+Shift+Z` 全局切换桌宠显示/隐藏。若该组合键已被其他软件占用，应用会通过托盘消息提示，其他功能不受影响。

聊天 API 配置保存在 `%APPDATA%\\深海待办桌宠\\chat_config.json`，不写入源码目录；聊天 API Key 和可选的 Tavily 搜索 Key 均使用 Windows DPAPI 机器范围加密，复制到其他电脑后不能解密。仓库根目录的 `.gitignore` 还会排除 `.env`、聊天配置、聊天记录、本地任务数据、构建目录和临时目录。上传 GitHub 前不要把 `%APPDATA%` 中的用户数据手动复制进仓库。

联网搜索按可用性排序：配置 Tavily Search API Key 后优先调用 `https://api.tavily.com/search`；没有 Key 时依次尝试无需 Key 的 360 搜索（`https://www.so.com/s?q=`，结果里的 `data-mdurl` 才是真实网址，href 是跳转链接）、Bing RSS（`https://www.bing.com/search?q=&format=rss`）、Bing HTML 和 DuckDuckGo HTML。

2026-10-04 实测：中文查询下 Bing 会返回与问题无关的页面、部分查询甚至解析不出结果列表，而无 Key 的 DuckDuckGo 一律返回 HTTP 202 验证码页，因此顺序调整为 360 优先、DDG 兜底。Tavily 提供免费额度，具体额度以其官方页面为准。若三个搜索源都不可用，程序会继续请求聊天模型进行离线回答，并明确约束模型不能编造最新结果、实时数据或来源网址。询问“现在时间/几点”时直接读取本机时间，不调用网络。

角色创意工坊文件放在 `%APPDATA%\\深海待办桌宠\\characters`，也可放在 `.exe` 同级的 `characters` 文件夹。首次通过托盘“创意工坊 -> 打开角色目录”时，程序会生成格式说明和 `character.example.json` 模板。

## 临时文件清理与“无法连接聊天 API”

单文件 EXE 会在每次启动时把整个运行环境解压到 `%TEMP%\_MEIxxxxx`。Windows 存储感知（Storage Sense）的“删除我的应用未使用的临时文件”以及联想电脑管家等清理工具会定期删除其中的空闲文件：被进程占用的 DLL 会保留，`base_library.zip` 会被删掉。此后第一次惰性导入标准库时报：

```text
[Errno 2] No such file or directory: 'C:\Users\<用户>\AppData\Local\Temp\_MEIxxxxx\base_library.zip'
```

在桌宠中表现为聊天才出现的“无法连接聊天 API”，因为聊天链路此时才导入 `urllib` 和 `ssl`。

`core/runtime_guard.py` 在启动时把 `base_library.zip` 中的模块和网络栈全部导入一次，这些模块常驻内存，因此运行中的桌宠即使临时目录被清空也不受影响，报错也会改为提示“请从托盘退出桌宠后重新打开”。启动前就已清空的情况只会发生在桌宠未运行时，下一次启动会重新解压，不影响使用。

如果想彻底避免清理，可在“设置 → 系统 → 存储 → 存储感知”中关闭“删除我的应用未使用的临时文件”，或把 `%TEMP%` 排除在电脑管家的清理范围之外。另外 `desktop_pet.spec` 使用 `upx=False`，避免压缩后的 DLL 触发杀毒软件和清理工具的误判。

## 余额气泡

悬停桌宠时，它脑袋旁边会弹出一个漫画式椭圆气泡（`paintEvent` 画椭圆 + 两个尾巴圆，文字留出足够内边距以免被椭圆的弧线切到）。数据来自 DeepSeek 官方接口 `GET https://api.deepseek.com/user/balance`（`Authorization: Bearer <API Key>`），金额是两位小数字符串，用 Decimal 解析；字号按 `15 + 8·log10(余额+1)` 缩放并限制在 15–40px，弹框尺寸随字号自动收紧。

位置由 `core/positioning.py` 的 `balance_bubble_position` 决定：优先桌宠右上角并向桌宠收 6px，右边放不下就翻到左上角；如果桌宠贴着屏幕上边导致上方放不开，就改成贴在它侧面。它始终贴着桌宠，不会跳到屏幕角落；已经占住那一侧的窗口（任务列表）会先让开，但实在放不下时宁可压住列表也不离开桌宠。余额在每次悬停时后台重查，20 秒内重复悬停复用上次结果做节流，悬停期间随 250ms 的 tick 持续刷新 —— 官方余额接口本身是实时的，之前 5 分钟的缓存会让气泡和官网对不上。配置保存后缓存立即失效重查。

官方没有 token 用量接口（`/user/usage`、`/usage`、`/dashboard/billing/usage` 等实测全部 404）；社区做法是带浏览器 userToken 读 platform.deepseek.com 的 `/api/v0/usage/amount|cost` 内部接口，属于非官方、会随网页改版失效，本程序不使用。
