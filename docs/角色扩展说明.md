# 角色扩展说明

复制 `assets/character.json` 创建新角色清单，设置显示 `size`、`anchor`、`hit_area`、主题颜色，以及各状态的 `frames`、`frames_per_strip`、`durations_ms`、`loop`。当前播放器支持横向四帧 PNG 条：单帧 `256x352`，四帧总尺寸 `1024x352`。任务模型和排序不读取角色配置，因此更换角色不需要改动 `core/`。

当前默认角色为 `assets/deepseek` 中的深海蓝发女仆角色，显示尺寸为 `112x154`。`idle`、`running_left`、`running_right`、`waving`、`waiting`、`review`、`jumping`、`sleeping` 和 `waking` 都是独立状态；`failed` 与 `working` 暂时复用稳定待机帧，保证调用这些状态时不会卡住状态机。拖动时根据实际移动方向播放左移或右移动作；按住但尚未移动时保持站立。

睡眠序列使用四姿态图：`sleeping` 从站立过渡到趴睡并停在最后一帧，`waking` 从趴睡恢复到站立后回到 `idle`。新增角色时应同步更新素材来源、许可和署名记录。
