# 创意工坊角色包

程序支持用户自己制作并替换桌宠，不需要修改任务、托盘或持久化代码。托盘菜单中的“创意工坊 -> 打开角色目录”会自动创建用户目录：

`%APPDATA%\深海待办桌宠\characters`

也可以把角色包放在绿色版 `.exe` 同级的 `characters` 文件夹中。用户目录优先用于创意工坊内容，程序目录适合随绿色版一起分发的角色。

## 默认 GPT 格式

每个角色一个独立文件夹：

```text
characters/
  my-deepsea-pet/
    character.json
    frames/
      idle-01.png
      running-left-01.png
      running-right-01.png
      wave-01.png
      success-01.png
      failed-01.png
      waiting-01.png
      review-01.png
      sleeping-01.png
      waking-01.png
```

每张 PNG 是 4 帧横向帧条：单帧 `256x352`，整张图片 `1024x352`。角色窗口默认显示为 `128x176`，程序会按 `durations_ms` 播放四帧。一个状态也可以在 `frames` 中列出多张帧条，程序会自动接着播放，例如两张帧条就是八帧。

打开角色目录后可以直接复制自动生成的 `character.example.json`，改名为 `character.json`，再把 GPT 输出的帧条放进 `frames` 文件夹。

## 配置字段

```json
{
  "id": "my-deepsea-pet",
  "name": "我的深海桌宠",
  "size": [128, 176],
  "cell_size": [256, 352],
  "anchor": [64, 170],
  "hit_area": [12, 8, 104, 165],
  "states": {
    "idle": {
      "frames": ["frames/idle-01.png"],
      "frames_per_strip": 4,
      "durations_ms": [320, 140, 140, 520],
      "loop": true
    }
  },
  "random_action_seconds": [20, 45]
}
```

必需状态是 `idle`、`running_left` 和 `running_right`。推荐同时提供 `waving`、`jumping`、`failed`、`waiting`、`review`、`sleeping`、`waking`。缺少左右移动时会退回待机；缺少睡眠或唤醒时会使用等待或挥手动作作为兼容回退。

`durations_ms` 的数量必须不超过实际帧数；`loop: false` 的状态由点击、保存、失败或唤醒逻辑播放一次后自动回到待机。`idle` 的随机静止间隔由 `random_action_seconds` 控制。

## 安全与回退

程序只读取角色包目录内的相对路径，拒绝 `..` 越界路径、绝对路径、缺少必需字段、尺寸过大的配置和不存在的 PNG。损坏或不完整的角色包不会影响任务数据，程序会跳过它并继续使用默认角色。切换角色只改变角色窗口的显示尺寸和动画资源，不改变任务、位置、托盘和持久化数据。

## GPT 输出建议

将站立图和睡眠图作为参考图上传给 GPT，并要求：透明背景、无文字、无气泡、无白底、固定角色比例、每张图片 4 帧横向排列、每帧 `256x352`。如果 GPT 无法输出透明 PNG，可以先使用纯绿色 `#00FF00` 背景，之后再进行抠图。
