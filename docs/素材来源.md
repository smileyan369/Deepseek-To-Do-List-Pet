# 素材来源

- `人物设计图片/standing-reference.png` 与 `人物设计图片/sleeping-reference.png`：用户提供的站立和睡眠姿势参考图，仅用于角色设计比对，不会被应用加载或打包。
- `人物设计图片/idle.png`、`running-right.png`、`waving.png`、`waiting.png`、`review.png`、`jumping.png`、`sleeping.png` 与 `waking.png`：用户使用 GPT/即梦等图像生成服务生成并保存到工作目录的角色动作图。`running-left-draft.png` 是未采用的方向草稿。应用只使用经过本地去绿、去装饰、缩放和对齐后生成的 `assets/deepseek/*.png`，不包含服务水印或外部下载素材。
- `人物设计图片/app-icon.png`：用户生成并确认的应用图标源图；构建时转换为 `assets/app.ico`，透明 PNG 副本用于系统托盘。
- `tools/prepare_deepseek_assets.py`：可重复执行的素材预处理脚本，输出透明 RGBA 四帧横向条（每帧 `256x352`，总尺寸 `1024x352`）。
- `assets/minty/spritesheet.webp` 与 `assets/minty/pet.json`：来自 [legeling/awesome-codex-pet](https://github.com/legeling/awesome-codex-pet) 的 `minty--somnusochi` 条目；角色及素材作者为 [Somnusochi](https://github.com/Somnusochi)，原始来源为 [Somnusochi/minty-codex-pet](https://github.com/Somnusochi/minty-codex-pet)。该条目 `submission.json` 明确标注 MIT License。本应用保持署名，并将素材用于桌宠待机、唤醒、拖动和睡眠动画。
- `assets/minty/spritesheet.png`：为兼容 Qt 单文件运行时，从上述 WebP 无损转换得到的 RGBA PNG；尺寸与像素内容保持一致。
