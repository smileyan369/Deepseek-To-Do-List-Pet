# 架构说明

`core/` 不依赖 Qt：`models` 提供任务和稳定排序，`store` 原子保存到 `%APPDATA%\\深海待办桌宠`，`interaction` 判定短按/长按，`positioning` 修复不可见屏幕位置，`animation` 以单一状态机避免睡眠与拖动冲突。

`core/single_instance.py` 使用当前 Windows 会话内的命名互斥量。首个进程持有互斥量直到退出；后续启动检测到已有实例后立即结束，不会创建第二个桌宠、托盘图标或数据写入者。

`app/global_hotkey.py` 通过 Windows `RegisterHotKey` 注册全局 `Ctrl+Shift+Z`，复用托盘的显示/隐藏切换逻辑，即使其他程序位于前台或桌宠已隐藏也能生效。注册使用禁止按键重复标志，应用退出时注销；快捷键被其他软件占用时仅显示托盘警告，不影响应用运行。

`app/` 负责 Qt 窗口、托盘、浮层和绘制。主窗口是 `Tool + Frameless + StayOnTop`，因此不进任务栏也不抢焦点。所有延迟收起使用 250ms 计时器并检查桌宠、任务表、编辑器的鼠标状态。

聊天功能由 `core/chat.py` 与 `app/chat_views.py` 分层实现：核心层负责 OpenAI 兼容接口、SSE 流解析、Windows DPAPI 加密聊天/Tavily Key、本地 JSON/Markdown 记忆和只读网页检索；界面层负责模式选择、配置、输入框、后台请求和逐字显示的底部锚定漫画气泡。气泡达到稳定最大高度后，长回复通过右侧细滚动条上下查看，短回复不会显示滚动条。未配置 API 时会直接打开配置窗口且不会发起聊天请求。开启“允许按需联网搜索”后，仅当问题包含搜索、新闻、天气、价格、最新等实时意图时才检索网页，优先 Tavily、失败后回退 DuckDuckGo，并把带来源网址的摘要作为不可信资料交给模型；搜索源全部失败时直接显示错误，不会静默降级为模型猜测。询问当前时间时由本机直接提供结果；该能力不授予执行程序或读取任意本地文件的权限。

`core/character_pack.py` 定义创意工坊角色包格式并负责安全发现：默认角色仍从内置 `assets/character.json` 加载，用户角色从 `%APPDATA%\\深海待办桌宠\\characters` 或绿色版同级 `characters` 目录加载。角色包只允许读取目录内的相对 PNG 路径；坏包跳过，选中的角色 ID写入设置。`CharacterWidget` 同时兼容旧的单精灵图行格式和 GPT 生成的四帧横向 PNG 帧条格式。

按压分界由 `core.interaction` 统一定义：小于 `200ms` 且移动不超过 7px 为短按；达到 `200ms` 即进入拖动。任务编辑器是独立可激活 Tool 窗口，显示后主动取得 Windows 前台焦点，避免桌宠主窗口的“不抢焦点”标志阻止键盘输入。

角色正常待机时固定显示站立帧，随机静止 `45–90 秒` 后播放一轮 idle 动画，然后重新进入静止期。睡眠时播放站立到趴睡的序列并停在末帧，用户交互后播放唤醒序列。中文输入通过 Qt 输入法事件处理，并在 Windows 上为编辑窗口重新关联默认 IME 上下文。

自动收起除检查鼠标是否位于桌宠或浮层外，还会检查编辑面板及其子控件的输入焦点。Windows 输入法候选窗出现时即使指针暂时位于面板外，只要编辑控件仍持有焦点，面板就不会关闭。

所有独立浮层在显示前都会按桌宠所在显示器的可用工作区校正。底部空间不足时输入面板移到角色上方，任务表左侧空间不足时切换到右侧；聊天气泡在保持底部锚点优先的同时限制在屏幕边缘内。

浮层收起使用 250ms 离开延迟，并在编辑器或聊天输入仍持有焦点时保持显示，以兼容 Windows 中文输入法候选窗口。

聊天是独立会话：聊天面板不再使用发送按钮，`Enter` 发送，`Shift+Enter` 在同一条消息内换行分段；右侧叉号或 `Esc` 是仅有的退出方式。鼠标移开、点击桌面或点击角色都不会结束聊天，避免输入与发送被自动收起打断。
